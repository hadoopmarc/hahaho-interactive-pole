## Intereractive Pole Quicktest

This is a useful small script that demonstrates the functionality of the Interactive Pole as of August 2026. Herman composed it using AI. These are the functionalities demonstrated:

 - sensing of the red button being pushed
 - sensing of passing people using the two PIR sensors
 - playing a sound file with the mp3-player
 - displaying a text on the Neopixel display
 - flashing the stroboscope light
 
 The functionalities it misses compared to the full firmware:
 
 - webserver with dashboard, serial monitor and OTA-updates
 - high level library to program the Interactive Pole without detailed knowledge of the sensors and actuators
